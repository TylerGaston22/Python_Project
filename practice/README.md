## The four basic data types

| Type | Example | Notes |
| --- | --- | --- |
| string | `"Jon"` | a series of characters, always in quotes |
| integer | `25` | a whole number, no quotes |
| float | `10.99` | a number with a decimal portion |
| boolean | `True` | only `True` or `False`, capital first letter |

`input()` always returns a **string**. Type cast it with `int()` or `float()`
before doing math with it.
